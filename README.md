# Docker Health Monitor

A Linux-based Docker container monitoring and automation project.

## Project Overview

This project demonstrates practical DevOps skills including:

- Linux system administration
- Bash scripting
- Docker container monitoring
- Git version control
- Infrastructure troubleshooting
- Automation

## Planned Features

- Detect stopped containers
- Detect unhealthy containers
- Report container status
- Return meaningful exit codes
- Automate scheduled health checks

## Technology Stack

- Ubuntu Server 24.04 LTS
- Docker
- Bash
- Git
